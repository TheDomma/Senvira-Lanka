# Senvira Lanka homepage

This is the first static homepage draft for Senvira Lanka.

## Files

- `index.html` contains the page sections and the small mobile navigation toggle.
- `styles.css` contains the colours, layout, typography, photos and mobile styling.

## Preview the page

Download or clone this repository, then open `index.html` in a browser. The page loads its typefaces and travel photos from the internet, so those parts need an internet connection.

## Before launch

The trip enquiry section is a visual placeholder. Add the real business email or WhatsApp link before inviting visitors to contact you. The current logo mark is a simple web drawing based on the approved brand direction; replace it with the final logo artwork when the logo file is ready.
